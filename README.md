# classification_from_scratch
This project is a basic example of a classification model built from scratch.

## Dataset
Training and valuation of the multinomial regressor is performed both on synthetic and benchmark datasets, including **MNIST** and **Fashion MNIST**.

- **Fashion MNIST**:
  - **Dataset License:** The MIT License (MIT) Copyright © 2017 Zalando SE
  - **Source:** retrieved via Kaggle.
  - **Description:** This dataset contains 70,000 grayscale images of 10 categories of clothing items (60,000 for the training set and 10,000 for the test set).
